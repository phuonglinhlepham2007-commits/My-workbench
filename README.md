# Linh's Pastel Workbench

A small, responsive personal dashboard built with plain HTML, CSS, and JavaScript. It uses a soft pink and cyan glass style and starts with only the confirmed name, Linh Lê. The dashboard categories remain empty until you add your own items.

## Open it

Open `index.html` in a modern browser. No build step or package installation is needed.

Tasks, notes, ideas, timer preference, and quick-entry labels are stored in this browser on this device using local storage. They are not sent to a server. Clearing browser site data will remove them.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Extract this ZIP and upload `index.html`, `styles.css`, `script.js`, and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select your default branch and the `/ (root)` folder, then save.
5. GitHub will show the published site link in the Pages section after deployment finishes.

The Google Fonts link is optional; the site falls back to system fonts if you are offline.
